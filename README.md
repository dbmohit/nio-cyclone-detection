# North Indian Ocean cyclone detection: ERA5 and CMIP6 (progress report website)

Interactive website for the preliminary analysis of cyclone tracking (UZ and OWZ trackers) in ERA5 for 28 RI/NRI storms and in 12 CMIP6 models (1950–2050, historical + SSP5-8.5), validated against the IMD best track (IBTrACS NI).

Open the site: see the GitHub Pages link in the repository's About panel.
